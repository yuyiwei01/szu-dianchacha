# 使用 SZU电查查

下载发布页中的 **SZU电查查.exe**，双击即可使用。只需一个文件，无需安装或管理员权限。适用于 Windows 10 / 11，使用系统自带的 PowerShell、.NET Framework 和默认浏览器。

源码版完整解压后，双击根目录 **启动SZU电查查.bat** 即可运行，无需安装 Python 或 Node.js。

## 首次查询

1. 连接可以访问学校 SIMS 电控系统的校园网或校内 VPN。
2. 打开程序，选择校区、楼栋，填写自己的房间号。
3. 点击“查询电量”。默认范围是近 30 天。

宿舍选择会自动保存，不必先完成查询。以后每次打开都会恢复“我的宿舍”，自动查询近 30 天。旧版用户已有的宿舍偏好会保留；新用户没有预设房间。

近 7 天、30 天、60 天和近一年是主要时间入口；自定义起止日期在“高级筛选”中。修改范围后点击查询。

## 图表与明细

“剩余电量”和“用电折线”自上而下独立展示。悬停或点选线段，可以查看间隔耗电、估算费用、充值金额和购买者。小图标由名字生成，不是学校提供的真实头像。

点击或按 Enter 可固定卡片，Esc 或点空白处关闭。日期较多时，通过每张图下方的滑块或横向滚动浏览，避免线段挤在一起。

侧边栏五个按钮定位到概览、剩余电量、用电折线和对应记录表。记录可以搜索、按购买形式筛选、改变排序，将筛选后的所有记录导出 CSV。

未连接校园网时可以“体验演示”。模拟数据不会覆盖真实缓存。查询失败时可查看上次缓存；“清除缓存”只删除查询明细，不会忘记宿舍。

## 数据含义与完整性

服务读取全部分页并核对学校声明的总条数。重复页、解析失败、缺失记录或总条数改变时会报告失败，不将部分结果当作完整查询。购电记录保留同一时间的多笔购买，也包含零金额补助。

用电量来自相邻累计读数之差，每天用最后一次读数计算。第一天没有前序读数时不计算耗电；跨日间隔显示日均值，累计读数回退的间隔排除统计。

剩余电量是范围内最新记录的数值，**不是实时余额**。预计可用天数以记录日期估算，没有扣除之后的用电。

自动电价为付费购电总金额除以对应度数，不含零金额补助，也可手动输入。费用仅供参考，不是学校账单。充值按相邻读数的完整时间区间归属；最新读数之后的购买仍保留在明细中。

## 本机保存与退出

服务只监听 `127.0.0.1`，数据由本机直接访问学校系统，没有云端中转。界面资源随程序提供。

- 宿舍偏好：`%LOCALAPPDATA%\SzuElectricity\preferences.json`，换浏览器、端口或更新 exe 后保留。
- 查询缓存：当前浏览器保存，不同浏览器和端口分别存储。
- exe 内置文件：`%LOCALAPPDATA%\SzuElectricity\app`。
- exe 日志：`%LOCALAPPDATA%\SzuElectricity\logs`；源码启动日志在项目数据目录。

重复双击同版本 exe 会打开已运行的服务。关闭浏览器不会结束服务，完全退出请点击“关闭查询服务”（手机布局为右上角“关闭服务”）。

删除 exe 即可移除启动入口。如需清理全部设置，请先关闭服务，再删除 `%LOCALAPPDATA%\SzuElectricity`，并在浏览器中清除缓存。

## 常见问题

**无法连接**：确认校园网或 VPN 能访问原电控查询页。学校服务不可用时可暂看缓存。

**房间不存在**：检查校区、楼栋，房间号通常只填数字。

**没有记录**：扩大范围，购电记录较少时试试近一年。单次查询最多三年。

**查询较慢**：程序逐页顺序读取，页面显示进度，可以取消。

**页面打不开**：重新启动并检查日志。源码版需要保留整个解压文件夹；exe 单文件可放在包含中文和空格的路径。

开发、测试和构建方式见 [开发说明](development.md)。
